# API-шар

Ця папка підготовлена до майбутнього підключення існуючого backend.

- `http.ts` — інстанс Axios з базовим URL (`VITE_API_BASE_URL`) та перехоплювачами.
- `generated/` — місце для клієнта, згенерованого з OpenAPI-специфікації.

Генерація типів (виконується вручну, коли зʼявиться специфікація):

```bash
bun run api:generate
```

Скрипт викликає `openapi-typescript` і записує результат у `src/api/generated/schema.ts`.

## Заміна mock-даних на реальний API

UI звертається лише до хуків (`src/features/*/hooks.ts`), які викликають репозиторії
з `src/mocks/repositories`. Щоб перейти на реальний backend, достатньо створити
реалізацію з тими самими сигнатурами (наприклад `src/api/repositories/products.ts`)
і підмінити імпорт у хуках. UI змінювати не потрібно.
