# Horpynka Admin Panel - Зміни

## Що було зроблено

Додано замокані дані та реалізовано їх відображення в UI для всіх основних розділів адмін-панелі.

### Створені файли з даними

**src/data/**
- `categories.ts` - 10 категорій (Гарячі страви, Гарніри, Супи, тощо)
- `ingredients.ts` - 20 інгредієнтів з одиницями вимірювання (г, мл, шт.)
- `dishes.ts` - 8 страв з прив'язкою до інгредієнтів
- `products.ts` - 18 товарів магазину
- `orders.ts` - 10 чеків з позиціями

### Створені репозиторії

**src/repositories/**
- `categories.ts` - Доступ до категорій
- `ingredients.ts` - Доступ до інгредієнтів
- `dishes.ts` - Доступ до страв
- `products.ts` - Доступ до товарів
- `orders.ts` - Доступ до чеків та позицій
- `menu.ts` - Формування меню з страв та товарів
- `transactions.ts` - Транзакції на основі чеків
- `cash-shifts.ts` - Касові зміни
- `inventory.ts` - Інвентаризації
- `dashboard.ts` - Статистика для панелі

### Реалізовані сторінки

1. **Панель (Dashboard)** - `/panel/dashboard`
   - Продажі за сьогодні
   - Кількість чеків
   - Готівка/Картка
   - Відкриті чеки
   - Поточна касова зміна
   - Графік продажів за 7 днів

2. **Чеки** - `/panel/orders`
   - Таблиця всіх чеків
   - Фільтрація за статусом
   - Пошук
   - Сортування
   - Деталі чека з позиціями - `/panel/orders/:id`

3. **Товари** - `/panel/products`
   - Таблиця товарів
   - Відображення категорії, цін, статусу
   - Пошук за назвою/категорією

4. **Страви** - `/panel/dishes`
   - Таблиця страв
   - Відображення категорії, цін, статусу
   - Пошук

5. **Інгредієнти** - `/panel/ingredients`
   - Таблиця інгредієнтів
   - Одиниці вимірювання
   - Пошук

6. **Меню** - `/panel/menu`
   - Об'єднане відображення страв та товарів, які продаються
   - Фільтрація та пошук

7. **Транзакції** - `/panel/transactions`
   - Історія фінансових операцій
   - Фільтрація за типом та способом оплати
   - Відображення повернень

8. **Касові зміни** - `/panel/cash-shifts`
   - Історія змін
   - Відображення початкових та кінцевих залишків
   - Статистика по зміні

9. **Інвентаризація** - `/panel/inventory`
   - Список інвентаризацій
   - Відображення розбіжностей
   - Детальний перегляд позицій

### Особливості реалізації

- Всі дані українською мовою
- Використання існуючих shadcn/ui компонентів
- Responsive дизайн
- Skeleton loading states
- Empty states з іконками
- Правильне форматування грошей (копійки → гривні)
- Форматування дат українською
- Сортування в таблицях
- Пагінація
- Фільтрація та пошук

### Структура даних

Всі дані відповідають доменній моделі з типами в `src/types/domain.ts`:
- Зв'язки між сутностями реалістичні (страва має інгредієнти, чек має позиції)
- Ціни зберігаються в копійках (integer)
- Дати в ISO формат
- Статуси з українськими лейблами

### Архітектура

```
UI компоненти (routes)
    ↓
React Query hooks
    ↓
Репозиторії (repositories)
    ↓
Замокані дані (data)
```

Така архітектура дозволить легко замінити замокані репозиторії на реальні API клієнти без зміни UI компонентів.
